# ArtMap Grid

Клиентский Fabric-мод для рисования на холстах ArtMap 32×32.
Автор: **ani_kaa (Vanilla Game)**.

- **G** — серая сетка по пикселям.
- **F** — крестики в четырёх центральных пикселях.
- **N** — розовая разметка равных секций.
- **Mod Menu → ArtMap Grid → Настройки** — секции 2×2, 4×4, 8×8, 16×16 или 32×32 пикселя,
  переключатели ориентиров, прозрачность серой сетки и показ только за мольбертом.

Все ориентиры независимы, видны только на вашем клиенте и не сохраняются в картине.
Клавиши можно переназначить в настройках управления Minecraft.

## Установка

Скачайте JAR для своей версии Minecraft из [Releases](https://github.com/Vanilla-Game/ArtMap-Grid/releases).
Установите Fabric Loader, Fabric API для той же версии игры и Mod Menu для экрана настроек.
Поместите только один JAR ArtMap Grid в папку `mods`, заменив предыдущую версию мода.

| Minecraft | Папка исходников | Java для игры |
| --- | --- | --- |
| 1.21.11 | `mc1.21.11` | 21+ |
| 26.2 | `mc26.2` | 25+ |

## Сборка и проверка

Установите JDK 25. Из корня репозитория выполните:

```sh
./gradlew -p mc1.21.11 -I verification/audit.init.gradle build auditCenterGeometry --no-configuration-cache
./gradlew -p mc26.2 -I verification/audit.init.gradle build auditCenterGeometry --no-configuration-cache
```

На Windows используйте `gradlew.bat`. Первая сборка загружает зависимости из интернета.
Готовые JAR находятся в `<папка версии>/build/libs/`; файлы `*-sources.jar` не предназначены для установки.
Общая версия хранится в `version.txt`, версия Minecraft добавляется к имени JAR.

## Релизы

Первый запуск release workflow собирает и публикует текущую версию с двумя JAR и SHA256SUMS.txt.
Дальше Release Please создаёт PR с изменениями `version.txt`, манифеста и CHANGELOG.md
по Conventional Commits (`fix:`, `feat:`). После слияния release PR этот же workflow
создаёт релиз, собирает обе версии и прикладывает JAR-файлы. Сборки не хранятся в Git.
Для повторного запуска доступен workflow_dispatch.

В Settings → Actions → General необходимо разрешить GitHub Actions создавать pull requests.
Если политика организации запрещает это, настройку должен изменить её владелец.

## Ограничения

Мольберт распознаётся по карте в рамке рядом с сиденьем из стойки для брони (ArtMap 3.9.26).
Проверены сборка и геометрия разметки. Проверка на сервере и совместимость с шейдерами
не заменяются этими проверками и требуют проверки в игре.
