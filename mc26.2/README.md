# ArtMap Grid — Minecraft 26.2 / Fabric

Клиентский мод с лёгкой серой сеткой 32×32 и крестиками в четырёх центральных пикселях холста мольберта.
Автор: **ani_kaa (Vanilla Game)**. В Mod Menu отображаются описание, автор и иконка холста.
Сетка — отдельный слой отрисовки: пиксели карты и сохраняемая картина не меняются.
Другие игроки её не видят. Серверный мод для сетки не требуется.

## Установка

1. Используйте Minecraft Java Edition **26.2**, Fabric Loader **0.19.5 или новее** и Java 25.
2. Установите **Fabric API для 26.2** (сборка проверена с `0.161.0+26.2`).
3. Замените предыдущий JAR мода на `artmap-grid-1.2.0+mc26.2.jar` в папке `mods` вашей игровой сборки и перезапустите игру.
   Для экрана настроек установите Mod Menu для 26.2. Без Mod Menu клавиши и сохранённые настройки работают.
4. Сядьте за мольберт ArtMap с холстом 32×32 и нажмите **G**.

## Управление

- **G** включает и выключает сетку; назначение можно поменять в настройках управления.
- **N** независимо включает и выключает розовую разметку равных секций.
  Размер по умолчанию — **8×8 пикселей**, то есть **4×4 секции** на холсте 32×32.
  Размер выбирается в **Mod Menu → ArtMap Grid → Настройки** через выпадающий список:

  | Размер одной секции | Количество секций на холсте |
  | --- | --- |
  | 2×2 пикселя | 16×16 |
  | 4×4 пикселя | 8×8 |
  | 8×8 пикселей | 4×4 |
  | 16×16 пикселей | 2×2 |
  | 32×32 пикселя | 1×1 (только внешняя рамка) |

  Изменения сохраняются сразу. На том же экране доступны переключатели всех трёх ориентиров,
  непрозрачность серой сетки и показ только во время сидения.
- **F** за мольбертом показывает или скрывает четыре крестика — в клетках 16–17 по обеим осям (нумерация с единицы).
  Светлые крестики с тёмной обводкой расположены внутри клеток и не закрашивают их целиком.
  Они переключаются независимо от сетки, поэтому можно оставить только обозначение центра.
  На распознанном холсте F не меняет предметы между руками, если обе команды назначены на одну клавишу.
  Вне холста обычная смена предметов работает как раньше.
- В разделе **ArtMap — сетка** можно назначить клавишу изменения прозрачности.
  Она переключает непрозрачность: 15%, 30%, 45%, 60%. По умолчанию эта клавиша не назначена.
- По умолчанию сетка появляется только во время сидения и скрывается, когда вы встаёте.
  Состояния трёх переключателей и выбранный размер секции сохраняются между запусками.

## Настройки

После первого запуска появится файл `config/artmap-grid.json`:

```json
{
  "enabled": false,
  "centerEnabled": false,
  "sectionsEnabled": false,
  "sectionSize": 8,
  "opacity": 0.3,
  "lineWidth": 0.18,
  "onlyWhileSeated": true
}
```

Редактировать файл следует при закрытой игре. `opacity` — непрозрачность,
`lineWidth` — ширина линии в точках карты Minecraft (клетка сетки занимает четыре точки).
`onlyWhileSeated: false` разрешает отображение на ближайшей вертикальной карте
в рамке в пределах трёх блоков и со стороны её лицевой поверхности.

## Совместимость и проверка

Реализация рассчитана на устройство мольберта из исходников **ArtMap 3.9.26**:
карта в рамке и сиденье из стойки для брони. Выбирается ближайшая к глазам игрока
вертикальная карта, обращённая к игроку, в пределах трёх блоков.
Это распознавание по геометрии, без подтверждения сервером: обычная карта рядом
с другим сиденьем из стойки для брони тоже может получить сетку.

Проверены сборка для Minecraft 26.2, геометрия крестиков внутри центральных клеток,
равные интервалы разметки для всех пяти размеров секций, отсутствие линий за пределами холста,
наличие ресурсов и соответствие мест
подключения к отрисовке байткоду этой версии. **Проверка в игре на сервере ArtMap
ещё не выполнена.** Совместимость с Sodium/Iris и шейдерами отдельно не проверена.

При первой проверке нарисуйте несколько одиночных пикселей в углах и центре:
каждый должен целиком попадать в одну клетку. Отключите сетку, сохраните картину
и убедитесь, что линии не появились в рисунке. Проверьте F при выключенной сетке:
должны появиться ровно четыре крестика, а предметы в руках должны остаться на месте.
Проверьте N при выключенных G и F: розовая разметка должна работать самостоятельно.
Выберите размер секции в Mod Menu, вернитесь к холсту и проверьте количество секций по таблице выше.
Если сервер меняет расположение
мольберта или размер холста, потребуется адаптация.

## Сборка из исходников

При установленной Java 25 запустите `gradlew.bat build` (Windows)
или `./gradlew build` (Linux/macOS). Результат — `build/libs/artmap-grid-1.2.0+mc26.2.jar`.
